This repository contains all files used to build my portfolio website.

the site can be viewed here.
https://kallenarkisto.github.io/Portfolio/

developed From a Bootstarp template.
Used Vite during development.

PlaceHolders are currently in use to view auto placement functionality 


During development I split the original template into React componets and added functionality inside their segments.

The added functionality is mainly:

Read data from a file. (data/projects) 

--> build a component from that data.

--> repeat for all items inside the data array.

--> place all these components and their individual data, including images and text, inside the Portfolio section.
